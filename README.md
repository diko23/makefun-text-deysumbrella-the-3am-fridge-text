Entry for [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) competition on make.fun.

The program writes a single-line, deadpan 3am smart-fridge status notification about a neglected crisper-drawer vegetable, staying within the 140-character UTF-8 gate.

## Run it

Runs on Node 22+ with standard library modules only (the grader executes `node /bot/main.ts`):

```sh
node main.ts
```

By default it writes to `/output/entry.txt`, or `$MAKEFUN_OUTPUT_DIR/entry.txt` when `MAKEFUN_OUTPUT_DIR` is set.
